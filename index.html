夜景写真VJシステム

夜景写真の光点をSEQTRAKのMIDIに同期して明滅させ、単眼深度推定で疑似3D化した空間を仮想カメラが移動する。開発中のツール群。

Phase 0

SEQTRAK Signal Monitor

SEQTRAKからの全MIDIメッセージをログ・集計し、トラック別のノート/CC番号を実測する。

 Phase 1

Night Light VJ

写真を読み込むと輝度マップを自動生成し、MIDIノートに応じて写真そのものの明るさを上げ下げする（カメラ固定）。

 Phase 1

Light Point Mask Editor

自動生成の代わりに、写真をクリックして輝度マップの元になる点を手作業で配置したいときに使う（任意）。
要件定義は docs/requirements.md を参照。
