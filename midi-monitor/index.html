このページはブラウザ内だけで動作し、MIDIデータはどこにも送信されません。
Chrome で SEQTRAK を USB-C 接続すると、画面上部の「MIDI入力デバイス」に表示されます （Yamaha Steinberg USB Driver のインストールが必要）。接続時にブラウザから MIDI アクセスの 許可を求められたら「許可」を選んでください。

ヒント: file:// で開くと Web MIDI がブロックされる場合があります。その場合は このフォルダで python -m http.server 8000 を実行し http://localhost:8000/ で開いてください。
