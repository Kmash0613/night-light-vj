Phase 1 — 手作業マスク作成

写真の上をクリックして光点を配置し、クラスタ（深度グループ）を割り当てる。作成した点群は points.json として書き出し、runtime/ ビューアーで読み込む。

Photo

写真をクリックして光点を追加。右のクラスタ選択で、追加する光点の深度グループ（0=最前景 〜 3=最遠景、目安）を切り替える。 1つ手前で削除したい場合は「元に戻す」。

上の「ファイルを選択」から夜景写真を読み込んでください。
画像はブラウザ内だけで処理され、どこにも送信されません。

Cluster

0: 最前景のネオン等 / 1〜2: 中景 / 3: 最遠景の窓明かり等 — config/midi-mapping.json の notes[].cluster と対応させる。

Points

書き出した points.json と写真ファイルを runtime/ のビューアーで読み込むと、 MIDIノートに応じて光点が明滅する。座標は画像に対する相対値(0〜1)で保存されるため、 元画像と同じアスペクト比であれば解像度が変わっても再利用できる。
