Phase 1

写真1枚・手作業マスク・カメラ固定。MIDIノートで光点が加算合成で明滅するかと、ブルームの見え方を確認する。

Scene

写真を読み込むと、輝度の高い場所から光点を自動抽出する（下の Auto Extract 参照）。 画像はブラウザ内だけで処理され、どこにも送信されない。

Auto Extract（輝度から光点を自動生成）

top %（明るい上位何%を光点にするか）3.0
min area（ノイズ除去、px）4
max points700

深度推定はまだ無い（Phase 2）ため、クラスタは「画面下ほど手前・面積が大きいほど手前」という 簡易ルールで割り当てる暫定版。config/midi-mapping.json の cluster と対応。 mask-editor/ で作った points.json を下の欄で読み込めば、 自動抽出の代わりに手動データを使うこともできる。

MIDI Input

Web MIDI へのアクセスを要求しています…

Cluster Envelopes

Light Points

size34
ambient breathing0.35

MIDIが鳴っていない間も、街が微かに息をするように光点を明滅させる量。 「呼吸する街」の土台（要件定義書 §1）。0にするとMIDIノートでのみ光る。

Background

luminance sway（写真自体の輝度ゆらぎ）0.30

元の写真も、明るい場所（ネオン等）ほど強くゆっくり明滅する。0で元の写真のまま静止。

Bloom（光点レイヤーのみ対象）

strength1.60
radius0.45
threshold0.12

カメラは固定（Phase 2で深度ディスプレイスメント＋移動を追加予定）。 マッピングは config/midi-mapping.json を読み込む。

左のパネルから写真と光点データを読み込むか、「サンプルを読み込む」で試してください。
