Night Light VJ

Phase 1

写真の輝度マップに応じて、写真そのものの明るさをKICKに連動させて上げ下げする。個別の光点は打たず、クラスタ分けも無い最小構成。カメラは固定。

Scene

写真を読み込むと、輝度の高い場所（ネオン等）から輝度マップを自動生成する（下の Auto Extract 参照）。 画像はブラウザ内だけで処理され、どこにも送信されない。

Auto Extract（輝度マップの自動生成）

top %（明るい上位何%をマップに含めるか）8.0
min area（ノイズ除去、px）4
max regions1500

クラスタ分けは無し。検出した領域はすべて同じ輝度マップに含まれ、KICKトラックの Note Onに連動して一律に明滅する（config/midi-mapping.json の name="KICK" のトラックを見る。無ければ cluster_trigger 全体をKICK扱いにする）。 mask-editor/ で作った points.json を下の欄で読み込むと、 自動抽出の代わりにその点群からマップを作る（clusterの値は現状無視される）。

MIDI Input

Web MIDI へのアクセスを要求しています…

Kick Envelope

Brightness

bright gain（明滅の強さ）1.20
ambient breathing0.35

輝度マップの値が乗っている場所だけ、MIDIノートに応じて元の写真の明るさを上下させる （マップが0の場所は写真のまま変化しない）。ambient breathing は MIDIが鳴っていない間の基準レベルで、そこを中心に明るく/暗く振れる （「呼吸する街」§1）。0にするとMIDIノートが無いときは写真のまま静止する。

Bloom

strength1.60
radius0.45
threshold0.55

通常のUnrealBloomPass。輝度がthresholdを超えた画素だけが光る （個別レイヤーではなく画面全体の輝度基準）。

カメラは固定（Phase 2で深度ディスプレイスメント＋移動を追加予定）。 マッピングは config/midi-mapping.json を読み込む。

左のパネルから写真を読み込むか、「サンプルを読み込む」で試してください。
